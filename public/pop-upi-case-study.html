02 · Design direction

Dark by default. Purple for action. Orange for reward.

The interface uses contrast and hierarchy to make high-value actions visible without turning the dashboard into visual noise.

Visual hierarchy

Near-black surfaces create the base for financial information. Purple identifies primary interaction and active states, while orange becomes the visual cue for POPcoins and rewards.

Interaction principle

Hover, elevation and state transitions reinforce where the user is, what can be clicked and what has changed.

03 · Design system

A reusable visual language for POP UPI desktop.

Tokens, typography, components, states and motion are documented as one system, using the same animated case-study language as the TAGX reference.

06 · Interaction rules

Scroll progress → top indicator. Section entry → fade + upward reveal. Navigation → animated underline. Cards → lift + subtle 3D tilt. Pills → lift + scale. Hero objects → pointer parallax. Large background words → scroll parallax. Reduced-motion preference → motion disabled.

07 · Reflection

A financial product can feel functional without feeling cold.

The POP UPI desktop direction balances financial clarity with a recognizable rewards identity.

The visual system combines dark surfaces, purple actions, orange POPcoin moments and clear transaction states across payment, commerce and rewards journeys.

Next, the interaction layer could be validated with usability testing focused on navigation, payment confidence, transaction comprehension, POPcoin redemption and discoverability.
